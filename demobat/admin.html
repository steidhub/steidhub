Tour Manager

Enter the password to add, edit or remove tour dates. No coding needed.

How to enter

  1. Type the password you were given.
  2. Press Enter.
  3. If it says the password is wrong, check capital letters and try again.

Pop-up

A message that opens on top of each show's own page (the page you share in ads). Use it for cancellations, refunds, venue changes or any notice. It has its own save button, separate from the tour dates.

How to use this section

  1. Tick Pop-up is on to turn it on. Untick it to hide it.
  2. Optional: pick a template and the title and message fill in for you.
  3. Edit the title and message in plain words: what happened and what fans should do.
  4. Optional: add a button (text and link), for example “Refund details”.
  5. Optional: choose dates to show it only for a period.
  6. Press Save pop-up. Use Preview this pop-up to see it first. Preview sign-up pop-up opens the community form the way fans see it.

Tour Dates

  • Add show creates a new row. Fill in the date, city and venue. Add a ticket link if you have one.
  • Nothing goes live until you press Publish. After that the website updates within a few seconds.
  • Past shows disappear from the site by themselves. Use Remove past shows to clean them out of this list.
  • No dates? Leave the list empty and the site shows a friendly “No dates scheduled” message.
  • Status and Update let you mark a show as cancelled, postponed or moved and add a comment that shows under it on the website.
  • Show page for ads (inside each show) makes a short page with the flyer, description and a ticket button. It is not linked from the website. Copy its link and use it in your ads.

How to fill in a show

  1. Date: the day of the show.
  2. City and Venue: where it happens.
  3. Tickets link: the page where fans buy tickets (optional).
  4. Note: a short extra line, like “All ages” (optional).
  5. Status: leave as normal, or pick Cancelled, Postponed or Moved, and write what happened in Update.
  6. Open Show page for ads to add a flyer and description and copy the link for your ads.
  7. When you finish, press Publish at the top. Nothing goes live before that.
